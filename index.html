OneDrive Date App

This single-file app writes and reads a simple ISO date file (default last_run_date.txt) into a folder you choose (pick a folder inside your OneDrive sync folder). It preserves the original upload/download features and adds better cross-device handling.

Drag a file here or click to choose a file to upload (fallback for browsers without folder access)
BehaviorPick a folder once; the app will remember it (IndexedDB). If your browser doesn't support folder access, use upload/download.
  • Save Today writes an ISO date string to the chosen folder (or downloads file if no folder).
  • Read Saved reads the file from the chosen folder or from an uploaded file.
  • Compare compares the saved date with today's date.
  • Upload lets you select a file to be read by the app (useful on mobile or unsupported browsers).
Tip: choose a folder inside your OneDrive sync folder so the file syncs across devices. On iOS use the upload/download flow to move the file into OneDrive.
