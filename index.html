OneDrive Date Saver

Save a single ISO date file into a folder that OneDrive syncs. Pick your OneDrive folder once, then use the buttons to write or read last_run_date.txt.

Notes and tips

How it works — the app asks you to pick a folder. Choose a folder inside your OneDrive folder (for example the root of OneDrive or a subfolder). The app writes a text file named last_run_date.txt containing the date in YYYY-MM-DD format.

Browser support — the File System Access API is supported in Chromium-based browsers (Chrome, Edge, Brave) on desktop and Android. If your browser does not support it, the app falls back to downloading the file; you can then move it into OneDrive manually or use the OneDrive app to upload it.

Tip — on Windows and macOS pick the OneDrive folder that your OneDrive client syncs. On Android use Chrome and pick the OneDrive folder if it is exposed by your system or use an rclone mount. On iOS use the download fallback and upload the file into OneDrive.
